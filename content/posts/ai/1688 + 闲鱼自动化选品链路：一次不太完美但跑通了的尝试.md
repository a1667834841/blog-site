## 1. 为什么做这个

最近一直在折腾闲鱼自动化。

前面已经把几个基础能力基本跑通了：竞品分析、商品上架、聊天、账号 token 刷新这些都能用了。真正卡住我的反而不是“能不能自动发布”，而是**选品太慢**。

有时候晚上花几个小时看竞品、找货源、对比价格、复制图片和文案，最后也不一定能挑出一个满意的商品。

所以我想试一下：  
能不能把「闲鱼竞品分析 → 1688 找货源 → 整理商品信息 → 自动发布到闲鱼」这条链路先跑起来。

这次不是做一个完整产品，而是先验证一件事：

> 1688 的货源数据，能不能和闲鱼 MCP 工具串起来，形成一个半自动选品和铺货流程。

---

## 2. 项目里用到的两个工具

这次主要用了两个项目：

- `xianyu-mcp`[https://github.com/a1667834841/xianyu-mcp ]：我自己写的闲鱼 MCP 工具，负责闲鱼侧的搜索、登录、发布、聊天等操作。
    
- `1688-cli`[https://github.com/superjack2050/1688-cli ]：用于从 1688 获取商品信息，比如标题、价格、图片、描述等。
    

这两个工具刚好可以拼起来：

一个负责找闲鱼上的竞品和发布商品，另一个负责去 1688 找对应货源。

## 4. 目前效果为什么还不够好

虽然链路跑通了，但实际效果还不能算好。

主要问题有几个。

### 4.1 只是“搬运信息”，还不是“选品判断”

现在流程更像是：

> 找到一个闲鱼竞品，然后去 1688 找一个可能类似的货源，再把信息填到闲鱼。

但它还没有真正判断：

- 这个商品质量好不好？
    
- 1688 的货源图和闲鱼竞品图是不是同款？
    
- 标题和图片有没有明显的违规风险？
    

也就是说，现在只是把流程自动化了，但选品质量还没有自动化。

### 4.2 还没有接视觉模型

现在主要依赖标题、关键词和商品信息匹配。

但是闲鱼和 1688 这类商品场景里，图片非常关键。很多时候标题不一样，但图一看就是同款；也有时候标题很像，但图片完全不是一个东西。

所以后面需要接入视觉模型，至少做几个判断：

```text
图片是否同款
主图质量是否足够
是否有明显水印
是否有拼接图 / 牛皮癣图
是否适合闲鱼展示
```

这一步不加的话，自动找货源的准确率会比较一般。

### 4.3 文案还没有按闲鱼风格重写

现在发布属于“铺货”，1688 的标题和

所以后面不能只是“复制文案”，而是要做成：

```text
1688 原始信息 → 清洗 → 提炼卖点 → 按闲鱼风格重写 → 人工确认
```

比如同一个商品，1688 可能写的是：

```text
厂家直供创意桌面收纳盒批发学生宿舍办公桌多功能置物架
```

放到闲鱼上更适合改成：

```text
桌面收纳盒，宿舍/办公桌都能用，东西多的可以看看
```

这种风格会更自然一些。

### 4.4 缺少最终审核工作台

现在最大的问题是：自动化跑完之后，不太好判断结果到底行不行。

比如系统已经生成了标题、描述、价格、图片，但我还是得自己打开链接，一个个看：

- 图片有没有问题
    
- 标题像不像真人写的
    
- 描述有没有违和感
    
- 价格是不是合理
    
- 货源和竞品是不是匹配
    
- 发布后的效果是否正常
    

所以后面最好做一个简单的审核工作台，把这些信息放在一起对比：

```text
闲鱼竞品        1688 货源        准备发布的闲鱼商品
标题            标题             改写后的标题
价格            进货价           发布价
图片            图片             最终图片
描述            描述             改写后的描述
链接            链接             发布预览
```

## 5. 后续准备怎么优化

后续我准备把重点放在几个方向。

### 5.1 商品信息清洗和模板化

先把 1688 的原始商品信息清洗一遍，去掉不适合闲鱼的内容。

比如：

```text
批发、厂家、代理、一件代发、起批量、联系客服、规格参数堆叠
```

然后再生成适合闲鱼的字段：

```text
闲鱼标题
闲鱼描述
商品卖点
适合人群
注意事项
价格建议
标签关键词
```

### 5.2 标题和描述改写

这一步不追求特别华丽，重点是自然。

我希望生成出来的文案不像“营销文案”，而像一个正常人在闲鱼发东西：

```text
东西是新的，买多了用不上。
适合宿舍、办公桌、出租屋用。
尺寸看图，介意的先问一下。
```

这个方向比“爆款标题生成器”更适合闲鱼。

### 5.3 图片处理


图片合规处理和素材整理。

比如：

```text
去掉重复图片
过滤低质量图片
识别明显水印
统一图片尺寸
生成发布前预览图
保留原始货源图用于追踪
```

这样表达更稳，也更像正常的商品素材管理。

### 5.4 加一个审核工作台

这是我觉得最重要的一步。

不一定一开始就做很复杂，先做一个最小版本就行：

```text
左边：闲鱼竞品
中间：1688 货源
右边：准备发布的商品
底部：通过 / 修改 / 放弃
```

只要能把对比成本降下来，选品效率就会提升很多。

---

## 6. 这次尝试的结论

这次跑下来，我的感觉是：

> 自动化发布本身不是最难的，难的是自动化判断“这个商品值不值得发”。

现在这条链路已经可以从闲鱼竞品一路走到 1688 货源，再映射到闲鱼发布表单。但它还只是一个“能跑通的流水线”，距离真正好用还有几个关键环节：

```text
图片相似度判断
商品质量评分
利润空间判断
文案自然化
发布前审核
```

所以后面的方向不是继续盲目提高自动发布速度，而是先把“选品判断”和“审核效率”做好。

否则发布得越快，可能只是更快地产生一堆质量一般的商品。

---

## 7. 文章结尾的一句话

这次算是一次 MVP 验证：  
先把 1688 和闲鱼的自动化链路接起来，再慢慢补上视觉识别、文案改写、商品评分和审核工作台。
