## 概念
守护线程：jvm不关心守护线程是否执行完成，如果用户线程全都执行结束，那么jvm就会退出
用户线程：jvm会等待所有用户线程全都执行结束，jvm才会退出

## 如何设置守护线程
```java
／／设置 为守护线程
daemonThread.setDaemon(true) ;
```
